# Customer-facing Streamlit view

Use the following URL for the customer-facing view:

`https://<your-app>.streamlit.app/?embed=true`

Streamlit documents that `embed=true` removes the toolbar, footer, extra padding, and colored top line.

The app code also hides the standard Streamlit header/menu in the normal app view.

The lower-right `Manage app` control is a Community Cloud management affordance shown to workspace/admin users; it is not part of the AskMoina UI and is not shown to ordinary public viewers.
